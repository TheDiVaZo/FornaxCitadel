# Ремонт и улучшение укреплений

ПКМ основной рукой с зарегистрированным материалом укрепления выполняет установку, ремонт или улучшение. Для сундуков, дверей, кроватей и других интерактивных блоков нужно присесть. Используются предметы из `citadel-types.<тип>.item`, включая материалы внешних провайдеров.

## Общая архитектура

Действие выбирается по состоянию блока и предмету в руке:

1. Укрепления нет — выполняется обычная установка.
2. Предмет соответствует текущему типу — выполняется ремонт, если здоровье неполное.
3. Предмет соответствует другому зарегистрированному типу — проверяется возможность улучшения.

Перед изменениями проверяются владелец, права, предмет и условия действия. Ремонт и улучшение меняют существующее укрепление, сохраняя его владельца, дополнительные данные и физический блок мира. Отказ проверки не расходует предметы и не меняет укрепление.

**Ремонт** восстанавливает здоровье до актуального `health.max` и сохраняет время начала созревания. При полном здоровье расхода нет. Без известного максимума или материала ремонт недоступен; отсутствие сохранённых HP при известном максимуме считается полным здоровьем.

**Улучшение** разрешено, если новый уровень строго выше известного старого. Если старый уровень неизвестен, допустим любой зарегистрированный новый тип с уровнем. Текущие HP и размер нового максимума на сравнение не влияют.

После улучшения здоровье становится равным максимуму нового типа; если максимума нет, сохранённое здоровье удаляется. Отсчёт созревания начинается заново по настройкам нового типа.

По умолчанию ремонт и улучшение доступны владельцу. Внешнее разрешение может открыть доступ к чужому укреплению с владельцем, но бесхозная цель всегда отклоняется. Владелец назначается при первоначальной установке и этими действиями не меняется.

| Действие | Необходимые права |
| --- | --- |
| Ремонт | `fornaxcitadel.repair` |
| Улучшение | `fornaxcitadel.repair` и `fornaxcitadel.place` |
| Улучшение до типа с `damage-policy: deny` | Дополнительно `fornaxcitadel.admin` |

Успешный ремонт или улучшение расходует один предмет из основной руки. В Creative предмет не списывается в обоих случаях.

При улучшении один предмет старого материала выпадает рядом с блоком по следующим правилам:

- Полное здоровье при известном старом максимуме гарантирует возврат. Отсутствие сохранённых HP при известном максимуме тоже считается полным здоровьем.
- В остальных случаях применяется `dismantle.refund-chance`; гарантированный возврат не зависит от этой вероятности.
- Если `item` старого типа неизвестен, возврата нет.

## Настройки

Механика использует общие настройки `config.yml`; отдельных разделов `repair` и `upgrade` нет. Пример с двумя стандартными типами:

```yaml
citadel-types:
  reinforced:
    item: minecraft:iron_ingot
    lvl: 2
    health:
      max: 20.0
  reinforced_heavy:
    item: minecraft:diamond
    lvl: 3
    health:
      max: 30.0
dismantle:
  refund-chance: 0.5
```

- `item` задаёт предмет для установки, ремонта и возврата; у разных типов должны быть разные ключи предметов.
- `lvl` — положительный целый уровень, по которому сравниваются типы при улучшении.
- `health.max` — положительный конечный максимум HP. Он обязателен для `damage-policy: allow`; у неуязвимого типа (`deny`) может отсутствовать.
- `maturing.duration-seconds` задаёт время созревания, а `initial-damage-multiplier` — множитель урона незрелому укреплению. Без `maturing` или при длительности 0 ожидания нет.
- `dismantle.refund-chance` — вероятность возврата старого материала от 0 до 1; стандартное значение 0.5 означает 50%. Здесь она используется для улучшений без гарантированного возврата.
- При установке и улучшении применяются ограничения материала блока и `placement.block-list`; они могут запретить действие даже при подходящем уровне.

Пользовательский `citadel-types` заменяет стандартный набор целиком: если нужны остальные типы, сохраните их в своём разделе. Пример выше содержит только два типа.

Изменения настроек применяются после перезапуска и действуют на существующие укрепления. Новый максимум сам по себе не лечит сохранённые HP; ремонт и улучшение используют актуальные значения.

## Сценарии использования

Взять нужный материал в основную руку → при необходимости присесть → нажать ПКМ по блоку. В примерах используется Survival, укрепление принадлежит игроку, права и ограничения допускают действие, если не указано иное.

| Ситуация | Результат |
| --- | --- |
| Железное укрепление имеет 5/20 HP; игрок использует железный слиток | Ремонт до 20/20 за один слиток. Время начала созревания сохраняется. |
| Железное укрепление уже имеет 20/20 HP | Ремонт не запускается, предмет не расходуется. |
| Укрепление уровня 2 имеет 5/20 HP; игрок использует алмаз для уровня 3 | Новый тип получает 30/30 HP, расходуется один алмаз, созревание начинается заново. Старый слиток возвращается с вероятностью 50% при настройках примера. |
| Укрепление уровня 2 имеет 20/20 HP; у нового типа настроены уровень 3 и максимум 10 HP | Улучшение разрешено: результат 10/10 HP и новый отсчёт созревания. Расходуется один новый предмет, старый возвращается гарантированно. |
| Другой тип имеет равный или меньший уровень, но больший максимум HP | Улучшение отклоняется; здоровье и предметы сохраняются. |
| Чужое укрепление без внешнего разрешения, бесхозная цель или недостаточные права | Ремонт или улучшение отклоняется без изменений и расхода предметов. |
